# Меблі від виробника — сайт

Односторінковий сайт-шаблон для меблевого шоуруму: каталог, підбір меблів (квіз), заявка, відгуки, питання, контакти. Чистий HTML, CSS і JavaScript, без збирання й залежностей.

## Структура

| Файл | Що в ньому |
| --- | --- |
| `index.html` | Розмітка сторінки, тексти розділів, SEO-розмітка |
| `assets/js/config.js` | **Усі дані, які змінюються:** контакти, графік, каталог, відгуки |
| `assets/js/app.js` | Логіка: каталог, квіз, форма, тема, статус шоуруму |
| `assets/css/style.css` | Стилі; кольори та шрифти — у блоці `:root` на початку |
| `assets/img/` | Ілюстрація першого екрана, іконка, картинка для соцмереж |
| `404.html`, `netlify.toml`, `robots.txt` | Сторінка помилки та налаштування хостингу |

## Що редагувати найчастіше

Усе нижче — у `assets/js/config.js`:

- **Телефон, Telegram, Viber** — впишіть значення, і кнопки з'являться самі. Порожні поля не показуються.
- **Графік роботи** — поле `hours`. Від нього залежить статус «Шоурум відкритий до …».
- **Каталог** — список `catalog`: назва, опис, ціна «від», характеристики. `price: 0` показує «уточнюйте».
- **Фото товарів** — покладіть файл у `assets/img/` і вкажіть шлях у полі `photo`. Вертикальні 4:5, від 800 px. Без фото показується ілюстрація.
- **Фото на першому екрані** — поле `heroPhoto`, горизонтальне фото від 1600 px.
- **Відгуки** — списки `reviews` (текстом) і `reviewShots` (скриншоти). Додавайте лише справжні відгуки.

Тексти розділів, питання й відповіді — у `index.html`. Якщо змінюєте питання, оновіть і блок `FAQPage` на початку файлу.

## Заявки

Форма та квіз надсилають заявки в **Netlify Forms** (форма `order`). Щоб вони надходили:

1. У панелі Netlify відкрийте сайт → **Forms** → увімкніть **Form detection**.
2. Задеплойте сайт ще раз.
3. Там же налаштуйте сповіщення на пошту.

Якщо надсилання недоступне, сайт показує готовий текст заявки з кнопками «Скопіювати» та «Відкрити Direct». Щоб працювати лише через Direct, поставте `formMode: 'direct'` у `config.js`.

## Локальний перегляд

```bash
python3 -m http.server 8000
```

Потім відкрийте <http://localhost:8000>.

## Перед запуском на власному домені

- У `index.html` замініть `og:image` на повну адресу (`https://ваш-домен/assets/img/og.png`).
- Додайте `sitemap.xml` і рядок `Sitemap:` у `robots.txt`.
